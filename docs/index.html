Arquitectura del Sistema

  1. Google Earth Engine (GEE): Procesa imágenes Sentinel-2 SR para obtener índices biofísicos.
  2. Flask Backend: Orquesta la verificación y genera el bloque de datos técnico.
  3. Criptografía Ed25519: Firma el bloque utilizando claves soberanas almacenadas de forma segura.
  4. ReportLab: Genera el certificado en PDF con código QR de verificación integrado.

Declaración de Diligencia

"Este sistema opera bajo un modelo de verificación soberana. Los datos satelitales son procesados directamente desde fuentes oficiales (Copernicus/ESA) y firmados digitalmente por la entidad emisora (ASPR-COF) para garantizar que la información no ha sido alterada desde su origen hasta la emisión del certificado."
